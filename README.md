## Web_LLM

# 🚀 Features

Einstein Persona – The model speaks in first person, using Einstein-style reasoning and experiences.

Conversational Memory – Chat history is passed to the model for coherent multi-turn dialogue.

Gradio Web Interface – Clean and simple UI for chatting, clearing history, and custom avatars.

LangChain Integration – Prompt templating, message formatting, and model invocation.

Google Gemini Support – Uses gemini-2.5-flash via ChatGoogleGenerativeAI.
